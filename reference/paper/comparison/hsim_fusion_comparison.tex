\begin{abstract}
Per-dataset comparison of recent HSI-MSI fusion methods (supervised,
unsupervised/blind, zero-shot, model-based). Only IEEE Xplore-indexed venues
(TGRS, TIP, TCSVT, CVPR) are included. One table per dataset, with columns:
paper title, method, year, type, scale, and one column per SOTA metric
(PSNR, SAM, SSIM, ERGAS) plus protocol. Values marked $\approx$ are OCR
recoveries from rasterized tables (approximate).
\end{abstract}

\section*{Legend}
PSNR$\uparrow$/SSIM$\uparrow$ higher is better; SAM$\downarrow$/ERGAS$\downarrow$
lower is better. \texttt{--} = not reported / not extracted; $\approx$OCR =
approximate; $\Delta$ = only improvement over a baseline reported; QNR = real
data (no PSNR/SAM). External baselines (BDT, FeINFN, CoFusion, SSA, Multi-path,
SMF2Net, DSPNet, 3DT-Net, PSRT, Fusformer, DHIF) are as provided; titles/DOIs
pending.
