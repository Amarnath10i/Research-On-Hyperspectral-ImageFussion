# PUFormer paper

**PUFormer: A Physics-Unfolded Transformer With Exact Observation Operators for Hyperspectral and
Multispectral Image Fusion**, IEEE journal format (IEEEtran), 9 pages: [main.pdf](main.pdf).

| File | Contents |
|---|---|
| `main.tex` | Manuscript |
| `references.bib` | 60 references; every entry with a DOI was taken from its Crossref DOI record |
| `numbers.tex` | Q2n-analysis numbers quoted in the text, generated by `make_numbers.py` |
| `figures/` | Figures, generated by `make_figures.py` (Fig. 1 is TikZ inside `main.tex`) |
| `make_figures.py`, `make_numbers.py` | Rebuild figures and numbers from the result files |

All numbers come from the committed result files:

* `results/puformer_chikusei_x4_v3/puformer/` (final model: `results.json`, `history.json`, `gaps.json`)
* `results/puformer_chikusei_x4_v3/first_run_reeval/` and `results/puformer_chikusei_x4/` (first run, SSR-NET)
* `results/puformer_chikusei_x4_v3/paper_analysis/` (`per_band.json`, `q2n.json`; `visual.npz` is kept
  locally, 16 MB). These come from `methods/puformer/paper_analysis.py`, run on Kaggle CPU by the
  notebook in `methods/puformer/kaggle/analysis/`.
* `results/puformer_chikusei_x4/tip26_table4_comparison.csv` (TIP'26 Table IV, reported values)

## Build

```bash
cd paper/puformer
python make_numbers.py      # numbers.tex from q2n.json
python make_figures.py      # figures/*.pdf (needs paper_analysis/visual.npz for Fig. 2)
tectonic -X compile main.tex
```

Tectonic (XeTeX) downloads the LaTeX packages it needs on the first run. The preamble loads TeX Gyre
Termes because XeTeX has no Type-1 Times for IEEEtran.
