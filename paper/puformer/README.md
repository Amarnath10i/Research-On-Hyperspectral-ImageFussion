# PUFormer paper

**Exact Observation Operators in Deep Unfolding for Hyperspectral and Multispectral Image Fusion**, IEEE
journal format (IEEEtran): [main.pdf](main.pdf). It covers:

* an ablation with one module changed per row, on Pavia Centre ×4 (three seeds for the key rows), Chikusei ×4 and CAVE ×4
* an equal-budget benchmark: PUFormer and five published networks (SSR-NET, PSRT, DCT, MIMFormer, DHIF-Net)
  retrained from their authors' code under one pipeline, on Chikusei and Pavia Centre at ×4/×8/×16 and on
  CAVE and Harvard at ×4/×8
* a comparison with the 17 methods reported for Chikusei ×4 and Pavia Centre ×4 by the TIP'26 study
* robustness to blur and spectral-response mismatch, with the true and an estimated blur supplied at test time

| File | Contents |
|---|---|
| `main.tex` | Manuscript |
| `references.bib` | References; every entry with a DOI was taken from its Crossref DOI record |
| `numbers.tex` | Chikusei Q2n-analysis numbers quoted in the text, generated by `make_numbers.py` |
| `tables/` | Generated tables: `make_tables.py` (comparison with reported results, Pavia values `\pav{...}`) and `make_q1_tables.py` (benchmark, ablation, blind-operator and complexity tables, values `\qone{...}`) |
| `figures/` | Figures, generated by `make_figures.py` and `make_q1_figures.py` (Fig. 1 is TikZ inside `main.tex`) |
| `build_paper_kernel.py` | Writes the Kaggle CPU notebook that runs the generators and Tectonic |

All numbers come from the committed result files:

* `results/puformer_chikusei_x4_v3/` (final Chikusei model, its first run and the Chikusei paper analysis)
* `results/puformer_chikusei_x4/` (first run, SSR-NET, TIP'26 Table IV Chikusei rows)
* `results/puformer_pavia_x4/` (Pavia Centre model, robustness, paper and SAM analysis, TIP'26 Table IV
  Pavia rows)
* `results/q1/<job>/` (one folder per benchmark / ablation job of `methods/puformer/kaggle/jobs.py`:
  `results.json`, `history.json`, `gaps.json`, `train.log`), `results/q1/blind-*/blind.json` and
  `results/q1/complexity.json`

Missing results print as `--` in the tables and `??` in the text, so the paper builds at any stage.

The `visual.npz` and `sam_maps.npz` files and the benchmark test predictions are not in git; the build
notebook takes them from the outputs of the Kaggle analysis kernels and from the prediction dataset
(`--q1data`).

## Build (on Kaggle)

```bash
cd paper/puformer
python build_paper_kernel.py              # writes kaggle_paper/ (sources + result files embedded)
kaggle kernels push -p kaggle_paper
kaggle kernels output amarnath10chinu/puformer-paper-build -p out   # main.pdf, figures/, tables/, numbers.tex
```

The notebook runs `make_numbers.py`, `make_tables.py`, `make_figures.py`, `make_q1_tables.py` and
`make_q1_figures.py`, downloads Tectonic and compiles `main.tex`. The preamble loads TeX Gyre Termes because
XeTeX has no Type-1 Times for IEEEtran.
