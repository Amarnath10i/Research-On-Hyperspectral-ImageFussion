# PUFormer paper

**PUFormer: A Physics-Unfolded Transformer With Exact Observation Operators for Hyperspectral and
Multispectral Image Fusion**, IEEE journal format (IEEEtran): [main.pdf](main.pdf). Results on Chikusei ×4 and
Pavia Centre ×4.

| File | Contents |
|---|---|
| `main.tex` | Manuscript |
| `references.bib` | References; every entry with a DOI was taken from its Crossref DOI record |
| `numbers.tex` | Chikusei Q2n-analysis numbers quoted in the text, generated by `make_numbers.py` |
| `tables/` | Tables with Pavia Centre numbers and the Pavia values quoted in the text (`\pav{...}`), generated by `make_tables.py` |
| `figures/` | Figures, generated by `make_figures.py` (Fig. 1 is TikZ inside `main.tex`) |
| `build_paper_kernel.py` | Writes the Kaggle CPU notebook that runs the three scripts and Tectonic |

All numbers come from the committed result files:

* `results/puformer_chikusei_x4_v3/` (final Chikusei model, its first run and the Chikusei paper analysis)
* `results/puformer_chikusei_x4/` (first run, SSR-NET, TIP'26 Table IV Chikusei rows)
* `results/puformer_pavia_x4/` (Pavia Centre model, robustness, paper and SAM analysis, TIP'26 Table IV
  Pavia rows)

The `visual.npz` and `sam_maps.npz` files are not in git; the build notebook takes them from the outputs of
the Kaggle analysis kernels `puformer-chikusei-paper-analysis` and `puformer-pavia-analysis`.

## Build (on Kaggle)

```bash
cd paper/puformer
python build_paper_kernel.py              # writes kaggle_paper/ (sources + result files embedded)
kaggle kernels push -p kaggle_paper
kaggle kernels output amarnath10chinu/puformer-paper-build -p out   # main.pdf, figures/, tables/, numbers.tex
```

The notebook runs `make_numbers.py`, `make_tables.py` and `make_figures.py`, downloads Tectonic and
compiles `main.tex`. The preamble loads TeX Gyre Termes because XeTeX has no Type-1 Times for IEEEtran.
