# Tools

Utilities for building and launching notebooks.

* `build_*_notebook.py` generate self-contained Kaggle notebooks for each method.
* `kaggle_autorun.py` and `push_all_proposals.py` push kernels and poll their status through the Kaggle API.
* `run_baseline_audit.py` runs the Stage-0 protocol audit (bicubic / GSA / Subspace-LS sanity).
* `make_variant.py`, `add_*_cells.py` edit notebooks.
